1. SYSTEM REQUIREMENTS
================================================================================

  Hardware (Minimum):
  ───────────────────
  • CPU:      2 vCPUs (x86_64 architecture)
  • RAM:      4 GB
  • Storage:  15 GB free disk space
  • Network:  Localhost access (no internet required after setup)

  Supported Operating Systems:
  ────────────────────────────
  • Kali Linux 2023.x or newer     (RECOMMENDED)
  • Ubuntu 22.04 LTS / 24.04 LTS
  • Debian 12 (Bookworm)
  • Any Linux distro with Docker support

  Network Ports Used:
  ───────────────────
  • Port 9000 — A.R.G.U.S. Threat Assessment Dashboard
  • Port 9001 — Syndicate Web Portal (Stage 04 target)

  NOTE: Ensure ports 9000 and 9001 are not in use by other services.
        Check with: sudo lsof -i :9000

2. PREREQUISITES INSTALLATION
================================================================================

  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 2.1 — Update System Packages                                 │
  └──────────────────────────────────────────────────────────────────────┘

    $ sudo apt update && sudo apt upgrade -y


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 2.2 — Install Docker Engine                                   │
  └──────────────────────────────────────────────────────────────────────┘

  Option A: Kali Linux
  ────────────────────
    $ sudo apt install -y docker.io docker-compose
    $ sudo systemctl enable docker --now

  Option B: Ubuntu 22.04 / 24.04 LTS
  ────────────────────────────────────
    # Install prerequisites
    $ sudo apt install -y ca-certificates curl gnupg lsb-release

    # Add Docker's official GPG key
    $ sudo install -m 0755 -d /etc/apt/keyrings
    $ curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
        sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
    $ sudo chmod a+r /etc/apt/keyrings/docker.gpg

    # Add Docker repository
    $ echo \
      "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
      https://download.docker.com/linux/ubuntu \
      $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
      sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

    # Install Docker Engine
    $ sudo apt update
    $ sudo apt install -y docker-ce docker-ce-cli containerd.io \
        docker-buildx-plugin docker-compose-plugin

  Option C: Quick Install Script (Any supported Linux)
  ─────────────────────────────────────────────────────
    $ curl -fsSL https://get.docker.com -o get-docker.sh
    $ sudo sh get-docker.sh
    $ sudo apt install -y docker-compose


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 2.3 — Add Your User to the Docker Group                      │
  └──────────────────────────────────────────────────────────────────────┘

    # This allows running Docker without sudo
    $ sudo usermod -aG docker $USER

    # IMPORTANT: Log out and log back in for this to take effect,
    #            or run: newgrp docker


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 2.4 — Verify Docker Installation                             │
  └──────────────────────────────────────────────────────────────────────┘

    $ docker --version
    # Expected: Docker version 20.10.x or newer

    $ docker-compose --version
    # Expected: docker-compose version 2.x.x or newer

    $ docker run hello-world
    # Expected: "Hello from Docker!" message


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 2.5 — Install Player Tools (Optional but Recommended)        │
  └──────────────────────────────────────────────────────────────────────┘

    # These tools are needed to SOLVE the challenges, not to run the platform.
    # Kali Linux includes most of these by default.

    $ sudo apt install -y \
        wireshark \
        tshark \
        python3 \
        python3-pip \
        gdb \
        binutils \
        ghidra \
        burpsuite \
        curl \
        wget

    # Volatility 3 (for advanced forensics — Stage 05)
    $ pip3 install volatility3

    # CyberChef (web-based, no installation needed)
    # Access at: https://gchq.github.io/CyberChef/

3. PLATFORM DEPLOYMENT
================================================================================

  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 3.1 — Obtain the Project Files                               │
  └──────────────────────────────────────────────────────────────────────┘

    # If you have the project folder, navigate to it:
    $ cd /path/to/alien

    # Verify the project structure:
    $ ls -la
    # You should see:
    #   docker-compose.yml
    #   README.md
    #   dashboard/
    #   portal/
    #   challenges/


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 3.2 — Build and Start the Platform                           │
  └──────────────────────────────────────────────────────────────────────┘

    # Build all containers and start in detached mode
    $ docker-compose up -d --build

    # This process will:
    #   1. Build the Dashboard container (Python 3.11 + Flask)
    #   2. Generate challenge artifacts:
    #      - telemetry.pcap (Stage 02 — network capture)
    #      - drone_core.raw (Stage 05 — memory dump)
    #      - doomsday.elf   (Stage 06 — compiled binary)
    #   3. Build the Portal container (Vulnerable Flask app)
    #   4. Create the Docker network (172.25.0.0/16)
    #
    # ESTIMATED BUILD TIME: 2-5 minutes (first build)
    #                       30 seconds (subsequent builds)


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 3.3 — Verify Deployment                                      │
  └──────────────────────────────────────────────────────────────────────┘

    # Check that both containers are running
    $ docker-compose ps

    # Expected output:
    #   NAME                STATUS          PORTS
    #   argus-dashboard     Up              0.0.0.0:9000->9000/tcp
    #   syndicate-portal    Up              0.0.0.0:9001->9001/tcp

    # Test the Dashboard
    $ curl -s http://localhost:9000 | head -5
    # Should return HTML content

    # Test the Portal
    $ curl -s http://localhost:9001 | head -5
    # Should return HTML content


  ┌──────────────────────────────────────────────────────────────────────┐
  │  STEP 3.4 — Access the Platform                                    │
  └──────────────────────────────────────────────────────────────────────┘

    Open your web browser and navigate to:

    ┌─────────────────────────────────────────────────────────┐
    │  A.R.G.U.S. Dashboard:   http://localhost:9000          │
    │  Syndicate Portal:       http://localhost:9001          │
    └─────────────────────────────────────────────────────────┘

    1. Enter an agent codename on the boot screen
    2. Read the mission briefing
    3. Begin with Stage 01 on the Threat Dashboard

6. MANAGEMENT & MAINTENANCE
================================================================================

  Start the platform:
  ────────────────────
    $ cd /path/to/alien
    $ docker-compose up -d

  Stop the platform:
  ───────────────────
    $ docker-compose down

  View live logs:
  ────────────────
    $ docker-compose logs -f              # All containers
    $ docker-compose logs -f dashboard    # Dashboard only
    $ docker-compose logs -f portal       # Portal only

  Reset all data (clear scores, restart fresh):
  ──────────────────────────────────────────────
    $ docker-compose down -v
    $ docker-compose up -d --build

  Rebuild a single service:
  ─────────────────────────
    $ docker-compose build dashboard
    $ docker-compose up -d dashboard

  Check resource usage:
  ─────────────────────
    $ docker stats argus-dashboard syndicate-portal

  Enter a container shell (debugging):
  ─────────────────────────────────────
    $ docker exec -it argus-dashboard /bin/bash
    $ docker exec -it syndicate-portal /bin/bash

7. TROUBLESHOOTING
================================================================================

  PROBLEM: "Port 9000 is already in use"
  ─────────────────────────────────────
    # Find what's using port 9000
    $ sudo lsof -i :9000

    # Stop the conflicting service, or change the port
    # in docker-compose.yml:
    #   ports:
    #     - "9002:9000"    # Use port 9002 instead


  PROBLEM: "Permission denied" when running Docker
  ──────────────────────────────────────────────────
    # Add user to docker group
    $ sudo usermod -aG docker $USER
    # Then log out and log back in

    # Or use sudo:
    $ sudo docker-compose up -d --build


  PROBLEM: Build fails with "network unreachable"
  ─────────────────────────────────────────────────
    # Docker needs internet to pull the Python base image
    # Ensure you have internet connectivity during the first build
    $ ping -c 3 google.com


  PROBLEM: "No space left on device"
  ───────────────────────────────────
    # Clean up unused Docker resources
    $ docker system prune -af
    $ docker volume prune -f


  PROBLEM: Container starts but website doesn't load
  ───────────────────────────────────────────────────
    # Check container logs for errors
    $ docker-compose logs dashboard
    $ docker-compose logs portal

    # Restart the containers
    $ docker-compose restart


  PROBLEM: Wireshark can't open the PCAP file
  ─────────────────────────────────────────────
    # Re-download the file from the dashboard
    # Or extract it directly from the container:
    $ docker cp argus-dashboard:/app/static/challenges/telemetry.pcap .


  PROBLEM: "Cannot connect to Docker daemon"
  ───────────────────────────────────────────
    # Start the Docker service
    $ sudo systemctl start docker
    $ sudo systemctl enable docker

8. UNINSTALLATION
================================================================================

  Remove the CTF platform completely:
  ────────────────────────────────────
    $ cd /path/to/alien
    $ docker-compose down -v --rmi all
    $ cd ..
    $ rm -rf alien/

  Remove Docker (optional):
  ─────────────────────────
    $ sudo apt remove -y docker-ce docker-ce-cli containerd.io
    $ sudo rm -rf /var/lib/docker
